==================================================
PHASED IMPLEMENTATION PLAN
==========================

IMPORTANT:

Do NOT attempt to build the entire platform blindly in one pass.

Build the application in clearly defined phases.

After completing each phase:

1. Run the application.
2. Check for TypeScript/build errors.
3. Check the browser console.
4. Check backend errors.
5. Test the functionality created in that phase.
6. Fix problems before moving to the next phase.
7. Preserve all working functionality from previous phases.

Do not move forward while a critical feature from the current phase is broken.

==================================================

IMPORTANT PHASE RULE
====================

Do not skip phases simply because the code appears to compile.

A phase is complete only when:

* It builds
* It runs
* Its main functionality works
* It has been tested
* Critical errors are fixed
* It does not break previous phases

Do not hide unfinished functionality behind buttons that appear to work.

Do not create fake success messages for functionality that is not implemented.

If an external integration cannot be completed because credentials are missing, clearly identify it as "configuration required" and implement everything that can safely be implemented without the credentials.

At the end of every phase, briefly report:

PHASE STATUS

* Completed:
* Tested:
* Issues found:
* Issues fixed:
* Remaining configuration:

Then continue to the next phase.

==================================================
FINAL STANDARD
==============

The goal is not simply to finish a website.

The goal is to build the foundation of a real international tourism company that can start in Kano, expand throughout Nigeria and Africa, and eventually operate worldwide.

Prioritize:

1. Correctness
2. Security
3. Real functionality
4. Professional UX
5. Scalability
6. Performance
7. Maintainability
8. Premium visual quality

Never sacrifice security or correctness simply to make the project appear finished.
